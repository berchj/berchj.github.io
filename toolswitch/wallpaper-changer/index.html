Shortcut: Super+Shift+W on Linux · Ctrl+Alt+W on Windows · Cmd+Option+W on Mac

What it does

Your wallpapers in a grid

Add folders or single images; click to add them to the rotation, double-click to set one now.

Automatic change

They rotate every few minutes or hours — you pick the interval.

Keyboard shortcuts

Random, next and previous wallpaper from anywhere.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Turn on Wallpapers in toolswitch and add a folder with images.
  3. Choose how often they change.
  4. Press the shortcut whenever you want a new one.

Use it instead of: Variety, Wallpaper Engine (for still images), John’s Background Switcher, Windows slideshow background.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

How do I change the wallpaper automatically on Ubuntu?

Install toolswitch, turn on Wallpapers, add a folder and pick an interval. It also works on Windows and macOS.

Can I change the wallpaper with a keyboard shortcut?

Yes: Super+Shift+W (Ctrl+Alt+W on Windows, Cmd+Option+W on Mac). You can record your own keys.
