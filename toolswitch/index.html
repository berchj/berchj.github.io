How to use it

  1. Download and install toolswitch. It starts in your tray / top bar.
  2. On the welcome screen, turn on the tools you want.
  3. Use them from anywhere with their shortcut, for example Super+Shift+V for the clipboard (Ctrl+Alt on Windows, Cmd+Option on Mac).
  4. Change any shortcut by clicking it and pressing the keys you like.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

What is toolswitch?

A small desktop app with 18 everyday tools — clipboard history, screen OCR, wallpapers, reminders, Google Calendar, breaks, file compressor, background remover, PDF signing, audio to text, tidy downloads, backup, clean up, PC monitor, shut down timer, updates, security check and Jira — that waits in your tray.

Is it like Microsoft PowerToys?

It’s in the same spirit, but it works the same on Windows, macOS and Linux, and it focuses on everyday tasks instead of developer tools.

Does it upload my files or what I copy?

No. Everything runs on your computer. The AI models for text from screen, background removal and audio to text are downloaded once and then work offline. Only Calendar and Jira talk to Google and Atlassian, and Security check to Anthropic’s Claude if you add a key — and only when you connect them.

How heavy is it?

The program is about 15 MB and uses about 90 MB of memory and almost no processor while it waits in the tray. A tool that’s off does nothing at all.

Can I use only some of the tools?

Yes. Each tool has its own switch; the ones you turn off don’t run.

Is toolswitch free?

Yes, it’s free to download and use. No account, no ads.
