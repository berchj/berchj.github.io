What it does

Disk almost full

A warning before you run out of space.

Stuck programs

When an app eats the processor or memory for a while, you get a notice with its name.

Close it from there

End the program from the notification.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Turn on Watch the PC in toolswitch.
  3. Keep working; it warns you when something is wrong.

Use it instead of: Task Manager, System Monitor, Activity Monitor, htop.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

Can it close system processes?

No. It only offers to close your own programs, not the system’s or other users’.
