Compress images, PDF, Word and PowerPoint offline — free

A file too big to email or upload? Drag it into toolswitch and get a smaller copy next to it, without sending it to any website.

⬇ Download toolswitch
Windows, macOS and Linux
Free · open source · MIT license

Shortcut: Super+Shift+T on Linux · Ctrl+Alt+T on Windows · Cmd+Option+T on Mac

What it does

Images

JPG and PNG, with a smart palette like TinyPNG.

Documents

PDF, Word, PowerPoint and Excel: it shrinks the photos inside; text and layout stay the same.

Many at once

Drag a whole batch.

Offline

The smaller copy is saved next to each file as name-min. Originals are never changed.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Press the shortcut or open Compress files.
  3. Drag your files in.
  4. The smaller copies appear next to the originals.

Use it instead of: TinyPNG, iLovePDF, Smallpdf, Adobe online compressor, tinyswitch.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

How do I reduce a PDF’s size without uploading it?

Drag it into toolswitch’s Compress files tool. It shrinks the images inside the PDF on your computer.

Will it ruin the quality?

Photos are recompressed to a size that looks the same on screen. Text, fonts and layout don’t change.
