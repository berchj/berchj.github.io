What it does

Local checks

Firewall, open ports, pending updates, screen lock, disk encryption, SSH and files with secrets.

Changes nothing by itself

Each fix is a setting to change or a command to copy.

Clear results

What’s fine, what isn’t, and why it matters.

A plan with Claude

With your own Anthropic API key, Claude writes the steps to fix each thing.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Press the shortcut or open Security check.
  3. Run the check.
  4. Follow the steps, or ask Claude for a plan.

Use it instead of: Lynis (for everyday users), Windows Security overview, security checklists.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

Does it send my data anywhere?

The checks run on your computer, offline. Only if you add an Anthropic key and ask for a plan, the settings it found (no files, no personal data) are sent to Claude.
