The Downloads folder fills up fast. toolswitch moves each file to its place as soon as it arrives, with rules you can turn on or off.

Shortcut: Super+Shift+O on Linux · Ctrl+Alt+O on Windows · Cmd+Option+O on Mac

What it does

By type

Documents, images, music, videos and installers, each to its folder.

Old files

Optionally, send what’s older than a few weeks to the trash.

Undo

Every move can be undone.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Turn on Tidy downloads in toolswitch.
  3. Check the rules and turn off any you don’t want.
  4. Download as usual; files go to their place.

Use it instead of: Hazel, DropIt, File Juggler, manual cleanup.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

Is there a Hazel alternative for Windows and Linux?

Yes: toolswitch’s Tidy downloads moves files by rules on Windows, Linux and macOS.

Is it on by default?

No. It only moves files after you turn it on.
