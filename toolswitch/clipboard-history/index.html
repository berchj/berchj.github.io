Free clipboard history manager for Windows, Mac and Linux

Copy something, copy something else, and the first thing is gone — unless you keep a clipboard history. toolswitch remembers everything you copy, text and images, and brings it back with one shortcut.

⬇ Download toolswitch
Windows, macOS and Linux
Free · open source · MIT license

Shortcut: Super+Shift+V on Linux · Ctrl+Alt+V on Windows · Cmd+Option+V on Mac

What it does

Everything you copy

Text, links and images (screenshots too), newest first.

Search as you type

Type a few letters to find something you copied days ago, then press Enter to paste it.

Pin favorites

Pinned entries stay at the top and are never deleted: addresses, replies, account numbers.

Private

The history lives only on your computer. Nothing is uploaded.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Turn on Clipboard history in toolswitch.
  3. Copy as you always do.
  4. Press the shortcut, pick an entry with the arrows or by typing, and press Enter.

Use it instead of: Windows clipboard history (Win+V), Ditto, CopyQ, Maccy, Paste, GPaste.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

How do I see my clipboard history on Linux or Mac?

Neither Ubuntu nor macOS keeps one. Install toolswitch, turn on Clipboard history and press Super+Shift+V (Cmd+Option+V on Mac).

Does it save images?

Yes: screenshots and copied pictures, with a preview. On Linux with Wayland it keeps text only for now.

Is my clipboard sent anywhere?

No. The history is stored on your computer and never leaves it.
