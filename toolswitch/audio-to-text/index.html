Transcribe audio to text offline with Whisper — free

A long voice message, an interview, a class recording: drop the file and get the text, without uploading it to any service.

⬇ Download toolswitch
Windows, macOS and Linux
Free · open source · MIT license

Shortcut: Super+Shift+A on Linux · Ctrl+Alt+A on Windows · Cmd+Option+A on Mac

What it does

Whisper

The speech recognition model by OpenAI, running on your computer.

~100 languages

Detects the language by itself.

Common formats

WhatsApp voice notes and videos, mp3, wav, m4a, ogg, flac, mp4, mkv and webm.

Offline and private

The audio never leaves your computer.

How to use it

  1. Download and install toolswitch. It waits in your tray / top bar.
  2. Press the shortcut or open Audio to text.
  3. Drag the audio or video file in.
  4. Copy the text when it’s ready.

Use it instead of: Otter.ai, online transcription sites, paid transcription services.

First launch: the installers aren’t signed with a paid certificate yet. On Windows click More info → Run anyway; on macOS open System Settings → Privacy & Security → Open Anyway.

Questions

Can I transcribe WhatsApp voice notes?

Yes, voice notes and videos. Save them to your computer (or use WhatsApp Web) and drag them in.

How fast is it?

A 35-second video takes about 7 seconds on a normal laptop with the best-quality model.

Does it need a graphics card?

No. It runs on the processor.
